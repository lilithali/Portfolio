### VR Avatar Intervention

A Unity-based VR research prototype that externalises self-critical thoughts through face-to-face interaction with a virtual avatar.

**My Contributions:**
- Developed the avatar interaction system for Meta Quest
- Integrated uLipSync and mapped speech to jaw, lip and mouth-corner movements
- Added blinking, eyebrow, cheek and subtle head-motion behaviours to reduce visual stiffness
- Implemented gaze tracking based on the participant's headset position to maintain eye contact
- Deployed and evaluated the prototype in a pilot study with 9 participants

**Demo:**

[VR Experience Demo](https://github.com/lilithali/vr-avatar-intervention/blob/main/demo/avatar_demo2.mp4)

**Technologies:** Unity, C#, Meta Quest, uLipSync, VR

### Remote Sensing Image Editing

A research project using diffusion models to edit dual-temporal remote sensing imagery and augment imbalanced change-captioning datasets.

**Highlights:**
- Fine-tuned InstructPix2Pix for instruction-guided remote sensing image editing
- Generated 5,230 edited remote sensing images
- Expanded the Levir-MCI dataset for downstream change captioning
- Evaluated the augmented dataset using RSICCformer

**Technologies:** Python, PyTorch, Stable Diffusion, InstructPix2Pix, Diffusers, Transformers, CLIP

[View Project Repository](https://github.com/lilithali/remote-sensing-image-editing)



### Face Morphing

Implemented a face morphing pipeline using facial landmarks, Delaunay triangulation, affine warping, bilinear interpolation, and image blending.

**Technologies:** Python, NumPy, Jupyter Notebook

**Highlights:**

* Built mesh-based correspondence between two face images.
* Implemented affine transformation and bilinear interpolation.
* Generated smooth intermediate frames and a morphing video.

[View Project Repository](https://github.com/lilithali/face-morphing)



### Ray Tracing with WebGL

Implemented a WebGL/GLSL ray tracer with geometric intersections, shadow rays, recursive reflection, refraction, Fresnel effects, and Boolean geometry.

**Technologies:** WebGL, GLSL

**Highlights:**
- Implemented sphere, plane, and cylinder intersection tests.
- Added shadows, recursive reflections, and refraction using Snell's law.
- Implemented Fresnel reflectance and Boolean geometry operations.

[View Project Repository](https://github.com/lilithali/ray-tracing)
